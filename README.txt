LES BRANCHY’S — prototype du site

Ouvrir index.html pour visualiser le site.

Contenus faciles à remplacer :
- data/events.json : prochains rendez-vous
- data/documents.json : documents et liens
- assets/ : images

La prochaine étape sera de connecter ces contenus à une interface simple (agenda / documents / album) afin de ne pas modifier ces fichiers à la main, puis de publier gratuitement le site.

Le bouton d’adhésion contient pour l’instant un lien # : il sera remplacé par l’URL HelloAsso définitive.
